# AdotePet

## Nome dos Integrantes:
- Diogo Honório Camarinha

## Descrição do problema social:
O projeto AdotePet aborda o problema do abandono animal e a superpopulação de animais de rua. A proposta é facilitar a adoção de pets, conectando pessoas interessadas com animais que precisam de um lar, tornando a adoção mais acessível e visível.

## Instruções para rodar o projeto:
1. Clone o projeto localmente ou faça download do ZIP:
   ```bash
   git clone https://github.com/<seu-usuario>/<seu-repositorio>.git
   ```
   ou use o botão "Download ZIP" e extraia o conteúdo.
2. Acesse a pasta do projeto:
   ```bash
   cd AdotePet
   ```
3. Instale as dependências obrigatórias:
   ```bash
   npm install
   ```
   Dependências usadas no projeto:
   - `expo`
   - `expo-status-bar`
   - `firebase`
   - `react`
   - `react-dom`
   - `react-native`
   - `react-native-safe-area-context`
   - `react-native-screens`
   - `react-native-web`
   - `@react-navigation/native`
   - `@react-navigation/native-stack`
4. Inicie o projeto Expo:
   ```bash
   npm start
   ```
5. Escolha o dispositivo web para rodar:
   - `w` para web

> Observação: certifique-se de ter o Expo CLI instalado globalmente (`npm install -g expo-cli`) ou use `npx expo start` se preferir.
